# VIT-AP FFCS Planner

A responsive weekly timetable planner for VIT-AP students. Search course codes, choose theory and lab sections, set availability, and compare clash-free schedules.

## Use
Open the deployed site, upload semester offerings (CSV, spreadsheets, PDF, or image), or start with sample data. Search a course code and select theory and lab slots before adding that section to a timetable. Data and uploaded files stay in the browser on the device. Export or print schedules when ready.

File extraction uses browser-side PDF, spreadsheet, and OCR libraries. Scanned or poorly formatted documents may need manual corrections. Generated theory/lab pairings and slot timings are suggestions; verify active semester offerings in VTOP.

## Deploy
Static website served from the repository root on Vercel. No build command is required.
